**1. Add `runReconciliation(options={})` to `src/scripts/payment-reconciliation.js`:**

Create a new exported async function `runReconciliation(options = {})` that encapsulates the logic from `main()` but accepts parameters via options instead of module-level CLI variables. The function should:

- Accept `{ tenantIndex = 0, fromDate = null, batchLimit = 20, pyFilter = null, dryRun = true }` from options
- Derive `shouldUpload` from `!dryRun` (inverted -- dryRun=true means shouldUpload=false, per user decision on dry-run defaults)
- Use `config.portal.tenants[tenantIndex]` to get tenant-specific values (id, key, secret, database) instead of module-level arrays
- Replicate the Step 1-5 logic from main(): fetch portal PENDING_TO_PAY, build portalUuidMap, query Sage, deduplicate, classify, upload (if not dryRun)
- Return a ResultEnvelope: `successResult(data, summary)` where data contains `{ portalInvoiceCount, sagePaymentCount, categories: { ready, no_providerid, no_uuid, not_in_portal, provider_mismatch }, autoResolvedCount }` and summary has the counts
- On error: return `errorResult([err.message], 'Reconciliation failed')`
- Keep console.log output for dual-output pattern (backward compat with CLI)
- Add to exports: `module.exports = { classifyPayments, uploadBatch, runReconciliation }`

IMPORTANT: Do NOT modify the existing `main()` function or the module-level CLI parsing code -- those are for backward CLI compatibility. The new `runReconciliation` function should be self-contained, using its own local variables derived from options.

const Joi = require('joi');

- `uuidRepairRepairSchema` (body): tenantIndex(int, 0-max, default 0), dryRun(boolean, default true)
- `uuidRepairUploadSchema` (body): tenantIndex(int, 0-max, default 0)
- `generatePaymentsSchema` (body): tenantIndex(int, 0-max, default 0), pyFilter(string, /^PY\d+$/, optional), dateFilter(string, /^\d{8}$/, optional), dryRun(boolean, default true)
- `cfdisSchema` (query): tenantIndex(int, 0-max, default 0)

Export all schemas.

**3. Create `src/routes/payment-routes.js`:**

```javascript
const express = require('express');
const router = express.Router();
const { validate } = require('../middleware/validate');
const { asyncHandler } = require('../middleware/async-handler');
const { sendResult } = require('../middleware/send-result');
const { writeLimiter } = require('../server');
```

NOTE: Importing writeLimiter from server.js may cause circular dependency. If it does, instead create the writeLimiter in a separate file `src/middleware/rate-limiters.js` or inline it in payment-routes.js using `const { rateLimit } = require('express-rate-limit')`. Prefer inlining a `writeLimiter` constant at the top of payment-routes.js to avoid circular deps.

7 routes:

a. `POST /reconciliation` -- validate(reconciliationSchema, 'body'), writeLimiter, asyncHandler: call `runReconciliation(req.body)`, sendResult
b. `GET /uuid-diagnostic` -- validate(uuidDiagnosticSchema, 'query'), asyncHandler: call `diagnosePayment({ docNbr: req.query.docNbr, tenantIndex: req.query.tenantIndex })`, sendResult
c. `POST /uuid-repair/scan` -- validate(uuidRepairScanSchema, 'body'), writeLimiter, asyncHandler: call `scanForRepairableUUIDs({ tenantIndex: req.body.tenantIndex })`, sendResult
d. `POST /uuid-repair/repair` -- validate(uuidRepairRepairSchema, 'body'), writeLimiter, asyncHandler: call `repairUUIDs({ tenantIndex: req.body.tenantIndex, dryRun: req.body.dryRun })`, sendResult
e. `POST /uuid-repair/upload` -- validate(uuidRepairUploadSchema, 'body'), writeLimiter, asyncHandler: call `uploadRepairedPayments({ tenantIndex: req.body.tenantIndex })`, sendResult
f. `POST /generate` -- validate(generatePaymentsSchema, 'body'), writeLimiter, asyncHandler: call `generatePayments({ tenantIndex: req.body.tenantIndex, pyFilter: req.body.pyFilter, dateFilter: req.body.dateFilter, shouldPost: req.body.dryRun === false })`, sendResult
g. `GET /cfdis` -- validate(cfdisSchema, 'query'), asyncHandler: call `getTypePTest(req.query.tenantIndex)` (positional arg -- thin adapter), sendResult

Pattern for each handler: validate -> [writeLimiter for POST] -> asyncHandler(async (req, res) => { const result = await scriptFn(params); sendResult(res, result); })
