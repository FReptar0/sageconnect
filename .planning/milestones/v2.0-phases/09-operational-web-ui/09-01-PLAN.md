**1. Create `public/js/` directory and `public/js/shared.js`:**

This is the shared JavaScript module loaded by every page. It must provide:

a) **Tenant state management:**
   - `TENANT_STORAGE = 'sageconnect_tenant'` localStorage key
   - `API_KEY_STORAGE = 'sageconnect_api_key'` localStorage key
   - `getTenantIndex()` -- returns parseInt of stored value, default 0
   - `setTenantIndex(idx)` -- saves to localStorage, reloads current page data
   - `window.__TENANTS__ = []` -- populated on init from /api/tenants

b) **API helper function `apiCall(method, path, body = null)`:**
   - Sets `Content-Type: application/json; charset=utf-8`
   - Sets `Accept: application/json; charset=utf-8`
   - If `localStorage.getItem(API_KEY_STORAGE)` exists, adds `x-api-key` header
   - If body is truthy, `JSON.stringify(body)` and attach
   - Returns `res.json()` promise
   - Catches network errors and shows toast

c) **Sidebar renderer `renderSidebar(activePage)`:**
   - Injects sidebar HTML into `<div id="sidebar">`
   - Fixed left sidebar, dark background (bg-dark text-white), ~220px width, min-height: 100vh
   - At top: SageConnect brand link (icon + text) pointing to /schedule.html
   - Below brand: Tenant switcher `<select id="tenantSwitcher">` with options from `window.__TENANTS__`
     - Each option: value = tenant index, text = tenant name (database field)
     - Selected value = `getTenantIndex()`
     - On change: calls `setTenantIndex(this.value)` which saves and calls `window.onTenantChange()` if defined, otherwise reloads
   - Horizontal divider
   - Nav pills (vertical): Programacion (/schedule.html, fa-calendar-check), Pagos (/payments.html, fa-credit-card), Ordenes de Compra (/pos.html, fa-file-invoice), Logs (/logs.html, fa-terminal)
   - Active page highlighted with Bootstrap `active` class

d) **Toast utility `showToast(message, type = 'success')`:**
   - Appends a Bootstrap 5.3 Toast to `<div id="toast-container">`
   - type 'success' = bg-success + fa-check-circle icon
   - type 'error' = bg-danger + fa-exclamation-triangle icon
   - type 'warning' = bg-warning text-dark + fa-exclamation-circle icon
   - Auto-dismiss after 5 seconds, removed from DOM after hidden

e) **Date/currency formatters:**
   - `formatDateTime(isoString)` using `Intl.DateTimeFormat('es-MX', { dateStyle: 'medium', timeStyle: 'short', timeZone: 'America/Mexico_City' })`
   - `formatCurrency(amount)` using `Intl.NumberFormat('es-MX', { style: 'currency', currency: 'MXN' })`
   - Return 'No disponible' / '$0.00' for falsy values

f) **Page init function `initPage(activePage)`:**
   - Fetches GET /api/tenants, populates `window.__TENANTS__`
   - Calls `renderSidebar(activePage)`
   - Sets up tenant switcher event listener

g) **Confirmation dialog `confirmAction(message)`:**
   - Uses `window.confirm(message)` -- returns boolean
   - Simple confirm is sufficient per research (not custom modal)

**2. Add GET /api/tenants to `src/routes/system-routes.js`:**

Add a new endpoint below the existing /health route:

```javascript
const config = require('../config');
const { successResult } = require('../utils/ResultEnvelope');

router.get('/tenants', (_req, res) => {
    const tenants = config.portal.tenants.map((t, i) => ({
        index: i,
        name: t.database || `Tenant ${i}`,
        id: t.id,
    }));
    res.json(successResult({ tenants }, 'Tenant list'));
});
```

No API key required (read-only, tenant names are not secrets). Import config and successResult at the top.
