<objective>
Create the LicenseValidator singleton service that verifies license validity against the remote server with HMAC signature verification, timestamp freshness checking, retry with exponential backoff, and a three-state cached model (VALID/INVALID/ERROR).

Purpose: This is the sole source of truth for license state in SageConnect. Every downstream consumer (startup gate in Phase 13's index.js, CronScheduler periodic checks, Express middleware) reads from this module's cached state. The HMAC verification prevents DNS/hosts file bypass attacks. The three-state model prevents Vercel outages from falsely blocking paying clients.

Output: `src/services/LicenseValidator.js` with `validate()`, `isValid()`, and `getStatus()` exports.
</objective>

    const LOG_FILE = 'LicenseValidator';
    const FRESHNESS_WINDOW_MS = 5 * 60 * 1000;      // 5 minutes
    const FUTURE_TOLERANCE_MS = 60 * 1000;            // 60 seconds
    const ERROR_TTL_MS = 24 * 60 * 60 * 1000;        // 24 hours
    const STARTUP_RETRIES = 3;
    const STARTUP_BACKOFF_BASE_MS = 1000;             // 1s, 2s, 4s

    **HMAC verification function (CRITICAL -- must match server exactly):**
    ```javascript
    function verifySignature(responseData, hmacSecret) {
        if (!responseData || !responseData.sig) return false;

        // Build payload in EXACT field order the server uses:
        // Success: { active: true, expiresAt: "...", ts: N }
        // Failure: { active: false, ts: N }
        const payload = { active: responseData.active };
        if (responseData.active === true && responseData.expiresAt !== undefined) {
            payload.expiresAt = responseData.expiresAt;
        }
        payload.ts = responseData.ts;

        const expected = crypto
            .createHmac('sha256', hmacSecret)
            .update(JSON.stringify(payload), 'utf-8')
            .digest('hex');

        const expectedBuf = Buffer.from(expected, 'utf8');
        const sigBuf = Buffer.from(String(responseData.sig), 'utf8');
        if (expectedBuf.length !== sigBuf.length) return false;
        return crypto.timingSafeEqual(expectedBuf, sigBuf);
    }
    ```

    **Timestamp freshness check:**
    ```javascript
    function checkTimestampFreshness(ts) {
        const now = Date.now();
        const age = now - ts;
        // Reject if older than 5 minutes
        if (age > FRESHNESS_WINDOW_MS) return false;
        // Reject if more than 60s in the future (clock skew protection)
        if (age < -FUTURE_TOLERANCE_MS) return false;
        return true;
    }
    ```

    **HTTP client:** Use `axios.create()` with a dedicated instance:
    ```javascript
    const licenseClient = axios.create({
        timeout: HTTP_TIMEOUT_MS,
        headers: { 'Accept': 'application/json' },
    });
    ```

    **validate() function (async):**
    - Accepts optional `{ startup: false }` options parameter
    - Makes GET request to `${config.license.apiUrl}/api/validate?key=${config.security.apiKey}`
    - On HTTP success (any 2xx):
      1. Verify HMAC signature. If invalid: set state to ERROR, log warning, return.
      2. Check timestamp freshness. If stale: set state to ERROR, log warning, return.
      3. If `active === true`: set state to VALID, update expiresAt and lastSuccessfulCheck
      4. If `active === false`: set state to INVALID, update lastSuccessfulCheck, send notification email
    - On HTTP error / network timeout:
      1. Set state to ERROR, log the error
      2. Check if lastSuccessfulCheck is older than ERROR_TTL_MS (24h): if yes, switch to INVALID
    - Always update lastChecked to current ISO timestamp
    - If `startup === true` and final state is not VALID:
      - Retry up to STARTUP_RETRIES times with exponential backoff (1s, 2s, 4s using `STARTUP_BACKOFF_BASE_MS * 2^attempt`)
      - After all retries exhausted: log error, send notification email, call process.exit(1)
    - Returns `{ valid: boolean, expiresAt: string|null, error: string|null, state: string }`

    **Email notification helper:**
    ```javascript
    async function sendLicenseAlert(subject, message) {
        try {
            // Build a custom email directly via nodemailer instead of EmailSender
            // because EmailSender.sendMail() uses config.mailing.notices array indexing
            // which doesn't support arbitrary recipient emails.
            // Use the same transport config from config.mailing.
            const nodemailer = require('nodemailer');
            const transportConfig = {
                host: config.mailing.server,
                port: config.mailing.port,
                secure: config.mailing.ssl,
            };
            if (config.mailing.password) {
                transportConfig.auth = {
                    user: config.mailing.from,
                    pass: config.mailing.password,
                };
            }
            const transport = nodemailer.createTransport(transportConfig);
            await transport.sendMail({
                from: config.mailing.from,
                to: config.license.adminEmail,
                subject: `[SageConnect] ${subject}`,
                html: `<h2>${subject}</h2><p>${message}</p><p><small>Company: ${config.app.company || 'Unknown'} | Time: ${new Date().toISOString()}</small></p>`,
            });
            logGenerator(LOG_FILE, 'info', `License alert email sent to ${config.license.adminEmail}: ${subject}`);
        } catch (err) {
            // Email failure must NOT block license validation flow
            logGenerator(LOG_FILE, 'warn', `Failed to send license alert email: ${err.message}`);
            console.warn(`[LICENSE] Failed to send alert email: ${err.message}`);
        }
    }
    ```
    NOTE: If `config.mailing.server` is not configured (mailing section is empty), the email will fail silently (caught by try/catch). This is acceptable -- not all deployments have mailing configured.
