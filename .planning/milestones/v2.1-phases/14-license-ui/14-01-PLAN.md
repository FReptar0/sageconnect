  <action>
Modify public/js/shared.js to add three capabilities: license status fetching, inactive banner, and expiry badge. All changes are pure vanilla JS using Bootstrap 5.3 classes already available on every page.

**1. Add a new `checkLicenseStatus()` async function** (place it in a new section between Toast Notifications and Date/Currency Formatters):

```javascript
/* ========================================================================
 * License Status Indicators
 * ======================================================================== */
```

The function:
- Fetches GET /api/system/license with Accept: application/json header
- Parses the response: `json.success && json.data` to extract `{ active, expiresAt, state }`
- On fetch error, silently returns (license UI is non-critical -- never block page load)

**2. Inactive banner (UI-09):**

After parsing the license response, manage a sticky banner element:

- If `state === 'INVALID'`: inject (or show if already exists) a full-width red banner at the very top of `document.body` (use `insertAdjacentHTML('afterbegin', ...)` on first creation). The banner:
  - id: `license-banner`
  - Text: "Licencia inactiva. Contacte a su proveedor."
  - Style: `position: sticky; top: 0; z-index: 1050;` (above Bootstrap navbar z-index 1030)
  - Bootstrap classes: `alert alert-danger text-center mb-0 fw-bold`
  - Icon: `<i class="fas fa-exclamation-triangle me-2"></i>` before text
  - No close button (operator cannot dismiss -- this is intentional)

- If state is NOT 'INVALID' (VALID, ERROR, UNKNOWN): remove the banner element if it exists (`document.getElementById('license-banner')?.remove()`)

- ERROR state does NOT show the banner per CONTEXT.md decision: "VALID/ERROR = hide". This prevents false alarms during Vercel outages.

**3. Expiry countdown badge (UI-10):**

After the banner logic, manage an expiry badge in the sidebar:

- If `expiresAt` is not null, compute days remaining: `Math.ceil((new Date(expiresAt) - Date.now()) / 86400000)`
- If days <= 30: inject a badge element into the sidebar (after the `<hr>` separator, before nav links)
  - id: `license-expiry-badge`
  - Text: `Expira en ${days} dias` (use "dia" singular if days === 1)
  - If days <= 7: Bootstrap classes `badge bg-danger` (red)
  - If days > 7 and days <= 30: Bootstrap classes `badge bg-warning text-dark` (yellow)
  - Wrap in a `<div class="px-2 mb-2">` for sidebar padding consistency
- If `expiresAt` is null OR days > 30: remove the badge element if it exists

- On each poll cycle, remove the old badge before potentially inserting a new one (avoids duplicates and ensures color transitions from yellow to red as expiry approaches).

**4. Wire into initPage():**

In the existing `initPage()` function, after the tenants fetch completes and `renderSidebar()` is called:
- Call `await checkLicenseStatus()` to do the initial license check
- Start a polling interval: `setInterval(checkLicenseStatus, 60000)` (60 seconds per CONTEXT.md)

The tenants fetch and license fetch should run in parallel for faster page load. Restructure initPage() to use `Promise.allSettled()` for both fetches, then process results: tenants first (needed by renderSidebar), then license status.

**5. Badge injection target:**

The expiry badge needs to be inserted into the sidebar after `renderSidebar()` builds the DOM. Inside `checkLicenseStatus()`, look for the sidebar's `<hr>` element: `document.querySelector('#sidebar hr')`. Insert the badge `<div>` after it using `insertAdjacentHTML('afterend', ...)`. If the sidebar is not yet rendered (edge case), skip badge injection silently.

**Important implementation notes:**
- Do NOT use ES6 arrow functions at the top level -- the existing shared.js uses `function` declarations consistently. Follow this convention.
- Do NOT add any new external dependencies -- all styling uses existing Bootstrap 5.3 classes and FontAwesome icons already loaded on every page.
- The banner goes on `document.body` (outside sidebar), the badge goes inside `#sidebar` (inside the nav column).
- Use `document.getElementById` for existence checks before creating/removing elements to prevent duplicates.
