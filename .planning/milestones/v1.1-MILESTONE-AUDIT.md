## Tech Debt

### Priority 1: PATH env var collision (CRITICAL)

`config.paths.downloads` resolves to OS `$PATH` (binary search path) instead of `./downloads` because `dotenv.config()` does not override pre-existing env vars. Same class of issue as `USER`→`DB_USER` that was fixed in Phase 4, but missed for `PATH`.

**Fix:** Rename `PATH` to `DOWNLOADS_PATH` in `.env`, `.env.example`, `src/config.js` REQUIRED map and config object. One-line changes in 3 files.

**Impact:** CFDI downloads and provider downloads will fail at runtime with `ENOENT` when trying to create directories at the OS PATH string.

### Priority 2: EnhancedPaymentSync.test.js latent risk

`tests/EnhancedPaymentSync.test.js` directly `require('../src/config')` without `jest.mock`. Excluded from Jest runs via `testPathIgnorePatterns` but would crash if run directly.

### Priority 3: Pre-existing test failures

3 test failures predate this milestone (TransformTime 2/3, PaymentReconciliation 1/24). Should be `test.skip`'d with explanatory comments to avoid confusion with migration regressions.

**Total:** 4 items across 2 phases
