## Escalation Items (outside RETRY-C1..C7's contract — require a developer decision)

These do **not** fail any RETRY-C1..C7 must-have (confirmed: none is named in the SPEC's literal acceptance text), but they are real, verified findings a careless pass would have hidden. Surfacing them per this agent's Escalation Gate design.

### E-1. CR-02 — RETRY-C7's dedupe does not cover `CANCELLED`, only `CLOSED`+`POSTED`

**Verified independently** (not just trusting the code review): `src/controller/PortalOC_Canceller.js:100-105` does `UPDATE ... SET status = 'CANCELLED' ... WHERE status = 'POSTED'` — it **replaces** the POSTED row, exactly like `PortalOC_Closer.js` does for `CLOSED`. After a Sage cancellation, no `POSTED` and no `CLOSED` row remains, so the new `NOT EXISTS ... status IN ('CLOSED','POSTED')` dedupe is still `TRUE` and the cron re-selects a cancelled PO — the identical 409-loop symptom RETRY-C7 was written to close, just from the other lifecycle terminus.

This is **not a failure of RETRY-C7 as specified** — the SPEC text (added by the 2026-07-22 Santiago-session amendment) says only "excludes both `POSTED` and `CLOSED`", never `CANCELLED`, and the code delivers exactly that. It is a genuine gap in what the amendment *should* have covered. It is mentioned in ROADMAP.md's Phase 20.2 entry ("CANCELLED (18) / OPEN (5) rows that the RETRY-C7 dedupe does not cover") but under the **"Explicitly deferred (NOT in this scope)"** bullet — meaning no currently-planned phase is actually scheduled to fix it. Recommend: either open a RETRY-C8 amendment, or explicitly widen Phase 20.2's scope, before the "todo junto" single deploy.

### E-2. CR-04 — `lastUpdate`/`createdAt` are typed `date` (no time-of-day) on `fesaOCFocaltec`

Per the production schema read cited in ROADMAP.md's Phase 20.2 entry, both columns are `date`, not `datetime`. Even after CR-01 (clock basis) is fixed, the 240-min PO interval has no time granularity to compare against without an `ALTER TABLE`. Also explicitly listed under Phase 20.2's "NOT in this scope" bullet — tracked, not scheduled.
