<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sage (APVENO.PROVIDERID) → URL del portal | El ID de proveedor sale de una columna opcional de Sage y entra a la query string de getCfdisByProvider |
| Portal → memoria del servicio | `items` y `total` del portal deciden cuántas páginas se piden y cuánto se acumula |
| Portal / Sage → GetTypesCFDI.log | Valores externos (providerId, códigos de error) se escriben en la bitácora de auditoría |
| GetTypesCFDI → scripts de conciliación | `getPendingToPayInvoices` alimenta `payment-reconciliation.js` y `pending-payments-diagnostic.js`, que interpretan "no está en la lista" como "no está en el portal" |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Tampering | URL de getCfdisByProvider (`providerId`) | mitigate | Todo valor de la query string pasa por `encodeURIComponent` (D-03); P-04 prueba que `P&1 2` llega como `providerId=P%261%202` y no agrega parámetros |
| T-24-02 | Denial of Service | Bucle de paginación en un servicio always-on | mitigate | Tope `CYCLE_MAX_PAGES = 50` (ciclo) y `maxPages` 1000 (scripts), corte `sin-avance` ante un portal que ignore `offset`, presupuesto del 25 % de `stepTimeoutMs`; el `Set` de dedupe es local a cada llamada; P-08, P-09, P-16 |
| T-24-03 | Denial of Service | Reintentos que rebasan el paso de 5 min | mitigate | Presupuesto revisado antes de cada intento y antes de cada espera; si la espera terminaría después del límite no se espera ni se reintenta (D-10); la única espera es `sleep()`, que termina sola; P-17 |
| T-24-04 | Tampering (integridad) | Lista parcial leída por los scripts de conciliación | mitigate | `getPendingToPayInvoices` conserva "todo o nada" y no tiene presupuesto (REQ-24-03, D-02); P-19 a P-22 deben pasar también contra el código de origin/master |
| T-24-05 | Tampering (inyección en log) | `proveedor=` y `status=` en las líneas `[PAGINACION]` | mitigate | `idLog`: el valor sale tal cual sólo si cumple `^[A-Za-z0-9_-]{1,64}$`; si no, `JSON.stringify(String(v).slice(0, 64))` (sin saltos de línea crudos) |
| T-24-06 | Information Disclosure | Cabeceras `PDPTenantKey`/`PDPTenantSecret` | mitigate | Las líneas nuevas nunca incluyen cabeceras ni la URL; sólo consulta, tenant, conteos, offset, status y proveedor |
| T-24-07 | Repudiation | Corte silencioso de la lista | mitigate | Una línea `[PAGINACION]` por consulta, `warn` con la causa cuando recibidas < total (D-17) |
| T-24-08 | Tampering | Sitios de interpolación SQL preexistentes en `getTypeP` | accept | Fuera de alcance (D-21, REQ-24-15): `getTypeP` conserva su lógica; este plan no agrega ningún sitio nuevo de SQL |
