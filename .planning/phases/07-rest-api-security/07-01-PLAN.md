  <action>
1. Install production deps: `npm install helmet@^8.0.0 cors@^2.8.5 express-rate-limit@^7.5.0`
2. Install dev dep: `npm install --save-dev supertest`

3. Create `src/middleware/api-key.js`:
   - Import config and errorResult from ResultEnvelope
   - Use `crypto.timingSafeEqual` for constant-time comparison of `req.headers['x-api-key']` against `config.security.apiKey`
   - If missing or invalid key, return `res.status(401).json(errorResult(['Invalid or missing API key'], 'Unauthorized'))`
   - Handle the case where SAGECONNECT_API_KEY is not configured (log warning, still reject)
   - Export `{ requireApiKey }`

4. Create `src/middleware/validate.js`:
   - Import Joi and errorResult from ResultEnvelope
   - Factory function `validate(schema, source = 'query')` returns Express middleware
   - Uses `schema.validate(req[source], { abortEarly: false, stripUnknown: true, convert: true })`
   - On validation error: map `error.details` to message strings, return `res.status(400).json(errorResult(errors, 'Validation failed'))`
   - On success: replace `req[source]` with validated+converted `value`, call `next()`
   - Export `{ validate }`

5. Create `src/middleware/async-handler.js`:
   - Simple wrapper: `fn => (req, res, next) => Promise.resolve(fn(req, res, next)).catch(next)`
   - Export `{ asyncHandler }`

6. Create `src/middleware/send-result.js`:
   - Helper function `sendResult(res, result)` that determines HTTP status from envelope:
     - `result.success === true` -> 200
     - `result.errors` contains `/not found/i` match -> 404
     - `result.errors` contains `/validation/i` match -> 400
     - Otherwise failed -> 500
   - Sets `Content-Type: application/json; charset=utf-8` header
   - Returns `res.status(status).json(result)`
   - Export `{ sendResult }`

7. Update `src/config.js`:
   - Add `security: ['SAGECONNECT_API_KEY']` to the `REQUIRED` object (BUT make it optional -- do NOT use the strict validation that calls process.exit. Instead, add a new OPTIONAL section or check after validate() and log a warning if missing).
   - IMPORTANT: The REQUIRED validation calls process.exit(1) on missing vars. SAGECONNECT_API_KEY should NOT crash the app if missing -- it should just disable API key protection with a console warning. Add it as an optional validated field.
   - Add `security: { apiKey: process.env.SAGECONNECT_API_KEY || null }` to the config object
   - After config object creation, add a warning: `if (!config.security.apiKey) console.warn('[CONFIG WARN] SAGECONNECT_API_KEY not set -- API key protection is DISABLED');`
  </action>

  </verify>
