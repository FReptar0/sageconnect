## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `process.env` → `config.*` | Untrusted env values cross into the runtime config object — if range guards miss a class of bad input, downstream SQL/HTML consumers receive that bad input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Tampering | `config.retry.lookbackDays` | mitigate | Range guard `Number.isInteger && in [1, 365]` exits 1 before any SQL interpolation; downstream Wave 2 plans inject the value into a template-literal SQL where a non-integer would either be rejected by SQL Server or interpreted as 0 — both paths blocked at boot |
| T-20-02 | Tampering | `config.retry.backoff.{initialMin,multiplier,maxMin}` | mitigate | Range guards (1≤initialMin≤60, 1.0≤multiplier≤10.0, 60≤maxMin≤10080) prevent negative/zero/NaN that could degenerate the JS post-filter `computeBackoffWaitMinutes` to `Infinity`/`NaN`/`-N` and bypass backoff entirely |
| T-20-03 | DoS | `config.eom.notificationEnabled` | mitigate | Type guard requires strict boolean; misconfigured `EOM_NOTIFICATION_ENABLED=' '` (whitespace) parses to `false` (kill-switch active) — fails closed not open. Boolean type guard catches non-string env tampering. The Wave 2 EOM gate short-circuits before any DB query when this is false |
| T-20-04 | Tampering | `config.retry.scope` | mitigate | Whitelist guard (`['current_month', 'last_n_days']`) rejects arbitrary strings before reaching the SQL builder — prevents WHERE clause injection via env var |
| T-20-05 | Information Disclosure | `[CONFIG ERROR]` messages | accept | Error messages echo the offending env value (`Got: ${value}`) to stderr; this is consistent with existing v2.3 guards at `src/config.js:185-208` and aids operator diagnosis. No PII in env values for this phase. ASVS L1 acceptable |
| T-20-06 | Tampering | `.env.example` defaults | mitigate | Customer-confirmation note in section preamble + acceptance criteria assert each commented default verbatim — accidental edits visible in PR review |
</threat_model>
