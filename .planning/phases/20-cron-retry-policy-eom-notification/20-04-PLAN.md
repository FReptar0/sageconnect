        const transportConfig = { host: config.mailing.server, port: config.mailing.port, secure: config.mailing.ssl };

    }
}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `subject` (string) → transport.sendMail subject field | Internal caller passes pre-formed subject (e.g., `[SageConnect] Pendientes fin de mes — POs — 2026-05`); not user input |
| `html` (string) → transport.sendMail html field | Internal caller passes HTML built by `buildEomEmailHtml` (20-03); row data sourced from internal SQL queries — not user input |
| `callerLogFile` (string) → logGenerator first arg → file path under logs/ | Internal caller passes hardcoded module name (e.g., `'EomNotification'`); LogGenerator sanitizes this value before path construction (existing behavior) |
| `config.mailing.notices` / `config.mailing.cc` → transport.sendMail to/cc fields | Operator-controlled env values parsed at boot; trusted per ASVS L1 operator-config posture |
| SMTP transport errors → warn log message body | nodemailer error.message; bounded by SMTP server response — no user input crosses this boundary |
