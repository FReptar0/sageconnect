<objective>
Create the CronScheduler service, modify forResponse() to emit progress events, and wire cron initialization into index.js.

Purpose: This plan internalizes the "run once and exit" background process into a recurring cron job managed by node-cron v4. The `forResponse()` function is modified to accept an options object with `operationId` and `emitter` so it can emit per-step per-tenant progress events (consumed by SSE in Plan 03). The CronScheduler acquires the `background-cycle` lock before each run and releases it after, recording execution history. index.js is updated to initialize the scheduler in always-on mode instead of calling `startBackgroundProcesses()` once.

Output: `src/services/CronScheduler.js`, modified `src/background.js`, modified `src/index.js`, unit tests green.
</objective>
