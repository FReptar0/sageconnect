| Boundary | Description |

| test harness -> global `Date` | A spy on a global clock leaks into every other test in the same worker if it is not restored. |
| test harness -> shared mock objects | A per-test override of `mockConfig.portal.*` leaks into the next test unless reset. |
| fixture strings -> git | Anything realistic placed in a fixture is a customer identifier committed to a public-facing repo. |
