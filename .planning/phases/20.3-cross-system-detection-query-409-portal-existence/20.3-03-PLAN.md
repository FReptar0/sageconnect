<objective>
Wire the portal existence probe into `createPurchaseOrders()`: build a function-scoped `errorCount`
lookup, run the probe as the first thing in the loop body gated on `errorCount > 0`, dispatch all six
outcomes with no fallthrough, INSERT one reconciliation row when the portal confirms it holds the OC,
and emit the two `[PORTAL-CHECK]` log labels. Repair the existing `cron-where` mock in the same commit,
because the wiring breaks it otherwise.

Purpose: this is the decision point the phase exists to add. Today `PortalOC_Creator.js` re-POSTs any
OC whose local rows are all `ERROR`, the portal answers 409 because it already holds the OC, another
`ERROR` row is written, and the loop is self-sustaining. After this plan the cron asks first — and when
the answer is yes, it records the portal's `idFocaltec` locally and stops POSTing, which is exactly the
detect-and-seed half of the lost-ack runbook (worked manually for PO0084361 / COPDAT on 2026-06-30),
automated.

Output: one contiguous new block at the top of the loop body, one `Map` build, one new INSERT site, one
summary line, a three-line mock repair, and a small structural-guard suite. The behaviour suite that
proves the six-row table is plan 20.3-04.

Decisions implemented (CONTEXT traceability) — **D-01**: the probe is an early `continue` at the very
top of the loop body, ahead of the Joi block, because the Joi failure path INSERTs an `ERROR` row and
running it for an OC the portal already holds would manufacture exactly the noise this phase removes.
**D-02**: a function-scoped `Map` keyed by trimmed `EXTERNAL_ID`, built from `recordset` before
`groupOrdersByNumber()` — `errorCount` is destroyed twice downstream (lowercased to `errorcount` at
`OC_GroupOrdersByNumber.js:20`, then dropped by the whitelist object literal at
`parseExternPurchaseOrders.js:86-119`), and editing either shared util is the CLAUDE.md §6 #2
blast-radius trap. **D-06**: two labels — `[PORTAL-CHECK]` per row with a `result=` field, and
`[PORTAL-CHECK-SUMMARY]` per tick — never one label per outcome. **D-07b**: the `cron-where` mock
repair lands in this same commit.
</objective>
